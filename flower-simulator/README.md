# 装花プランシミュレーター

花屋向けの「装花シミュレーション Web アプリ」テンプレートです。

ブライダル・パーティー・展示会・ポップアップ・法人イベントなどで装花を検討しているお客様が、
**花屋との本打ち合わせ前に、自分の希望・予算・世界観を整理できる**ヒアリングツールです。

質問に沿って選択・入力していくと、最後に「装花プランシート」が生成され、
印刷（PDF保存）・メール送信・コピーができます。

> **このアプリは、正確な見積もりや完成イメージを保証するものではありません。**
> あくまで、お客様の曖昧なご希望を整理し、初回打ち合わせをスムーズにするためのツールです。

## 主な機能

| 機能 | 内容 |
| --- | --- |
| トップページ | アプリ名、キャッチコピー、利用の流れ、注意事項 |
| 全10ステップの入力 | シーン／基本情報／予算／テーマ／テイスト／カラー／季節の花／装花場所／参考イメージ／連絡先 |
| 入力途中の自動保存 | ブラウザの localStorage に自動保存。ページを閉じても続きから再開できます |
| 季節の花の自動表示 | 開催日の「月」から、その時期におすすめの花を表示します |
| シーン別の装花場所 | ブライダルなら「高砂」「ブーケ」、展示会なら「展示ブース」などを自動で追加表示 |
| プランタイトルの自動生成 | 選択したカラー・テイスト・季節・シーンからルールベースで生成（外部AIは不使用） |
| コンセプト文の自動生成 | 同じくルールベースで短い文章を生成 |
| 予算配分案 | 装花場所の重み × 優先度の係数で概算を配分。搬入設営費・撤去費も自動で確保 |
| 参考画像のアップロード | ブラウザ内で圧縮・プレビューのみ。サーバーには送信されません |
| 結果の出力 | 印刷（PDF保存）／JSONダウンロード／クリップボードにコピー／メール本文の生成 |
| 花屋への相談導線 | mailto・Googleフォーム・外部フォーム・LINE から設定ファイルで選択 |
| 法的ページ | プライバシーポリシー・利用規約（テンプレート） |

## 技術構成

- **Next.js 16**（App Router）
- **TypeScript**
- **Tailwind CSS v4**
- **React Hook Form**（フォーム管理）
- **Zod**（入力チェック）
- **Lucide React**（アイコン）
- スマートフォンファースト／日本語UI
- **外部AI API・有料API・Supabase・データベース・ログイン機能・管理画面は一切使用していません**

## ローカルでの起動方法

### 事前準備

[Node.js](https://nodejs.org/ja) の **20.9 以上**（推奨：22 以上）をインストールしてください。
ターミナル（Mac は「ターミナル」、Windows は「PowerShell」）を開いて、次のコマンドでバージョンを確認できます。

```bash
node -v
```

### 手順

```bash
# 1. このフォルダに移動します
cd flower-simulator

# 2. 必要なライブラリをインストールします（初回のみ・数分かかります）
npm install

# 3. 開発サーバーを起動します
npm run dev
```

ブラウザで **http://localhost:3000** を開くとアプリが表示されます。
終了するときは、ターミナルで `Ctrl` + `C` を押してください。

### その他のコマンド

```bash
npm run build      # 本番用にビルドします（公開前の動作確認に使います）
npm run start      # ビルドしたものを起動します
npm run lint       # コードのチェックをします
npm run typecheck  # 型のチェックをします
```

## Vercel へのデプロイ方法

無料で公開できる [Vercel](https://vercel.com/) を使う手順です。

1. [GitHub](https://github.com/) にアカウントを作り、このフォルダをリポジトリとしてアップロードします。
2. [Vercel](https://vercel.com/) に GitHub アカウントでログインします。
3. 「**Add New…**」→「**Project**」を選び、1 で作ったリポジトリを選択します。
4. 設定はそのままで大丈夫です（Framework Preset に自動で「Next.js」が入ります）。
   - このアプリを**サブフォルダ**（例：`flower-simulator/`）に置いている場合は、
     「**Root Directory**」に `flower-simulator` を指定してください。
5. 「**Deploy**」を押すと、数分で公開URLが発行されます。

環境変数の設定は不要です。

以後、GitHub に変更をアップロードすると、自動で再デプロイされます。

## 自店仕様へのカスタマイズ

**基本的な変更は、すべて次の1ファイルだけで完結します。**

```
src/config/shop.ts
```

このファイルには日本語のコメントが付いています。
`'` （シングルクォート）で囲まれた文字や、数字を書き換えるだけで反映されます。

> ⚠️ 編集するときの注意
> - 文字は必ず `'` で囲んでください。
> - 行末の `,`（カンマ）は消さないでください。
> - 保存したらブラウザを再読み込みしてください（`npm run dev` 実行中なら自動で反映されます）。

---

### 1. 店名・ロゴの変更

`src/config/shop.ts` の上のほうにあります。

```ts
appName: '装花プランシミュレーター',   // ← ブラウザのタブや画面右上に出る名前
shopName: 'Atelier Fleur',            // ← お店の名前
logo: '/images/logo.svg',             // ← ロゴ画像のパス
catchCopy: 'まだ言葉になっていない理想の景色を、\n花屋との打ち合わせ前に整理する。',
description: '開催シーンやご予算、好きな色、雰囲気、季節の花を選ぶだけで、装花相談用のプランシートを作成できます。',
```

**ロゴ画像を差し替える手順**

1. ロゴ画像（PNG / SVG / JPG）を `public/images/` フォルダに置きます。
   例：`public/images/logo.png`
2. `logo: '/images/logo.png',` と書き換えます（先頭の `/images/` は必ず付けてください）。
3. ロゴを使わず店名の文字だけにしたい場合は `logo: '',` にします。

**キャッチコピーの改行**は `\n` で入れられます。

---

### 2. ブランドカラーの変更

```ts
brand: {
  primary: '#6B7F63',            // メインカラー（ボタン・見出し）
  primaryForeground: '#FFFFFF',  // メインカラーの上に乗る文字色
  accent: '#B08A64',             // アクセントカラー（選択中の枠線など）
  surface: '#FAF8F5',            // 背景の淡い色
  text: '#2E2A26',               // 本文の文字色
  muted: '#7A736C',              // 補足テキストの色
  border: '#E5DFD7',             // 罫線の色
},
```

`#` で始まる6桁のカラーコードで指定します。
カラーコードが分からない場合は、Google で「カラーピッカー」と検索すると調べられます。

> 💡 `primary` を濃い色にしたときは、`primaryForeground` を `'#FFFFFF'`（白）に、
> 淡い色にしたときは `'#2E2A26'`（黒に近い色）にすると読みやすくなります。

### 3. フォントの変更

```ts
fontFamily: {
  base: '"Hiragino Sans", "Noto Sans JP", "Yu Gothic", "Meiryo", sans-serif',
  heading: '"Hiragino Mincho ProN", "Yu Mincho", "Noto Serif JP", serif',
},
```

`base` が本文、`heading` が見出しのフォントです。
左から順に「そのフォントがあれば使う」という指定なので、複数書いておくと安心です。
見出しを明朝体にすると上品な印象になります。

### 4. シーンの変更

`scenes:` の中を編集します。1つのシーンは `{` から `}` までがひとかたまりです。

```ts
{
  id: 'bridal',                 // 内部で使うID（半角英数字。他と重複しないように）
  name: 'ブライダル',            // 画面に表示される名前
  description: '挙式・披露宴・二次会などの結婚式まわりの装花',
  image: '/images/scenes/bridal.svg',
  titleWord: 'ウェディング',      // 自動生成されるプランタイトルに使われる言葉
  extraAreaIds: ['takasago', 'guestTable', ...],  // このシーンだけで表示する装花場所
},
```

- **削除したいシーン**：`{` から `},` までを丸ごと消します。
- **追加したいシーン**：既存のかたまりをコピーして貼り付け、`id` を他と重複しない名前に変更します。

### 5. テイストと画像の変更

`styles:` の中を編集します。

```ts
{
  id: 'natural',
  name: 'ナチュラル',
  description: 'グリーンや枝ものを生かし、作り込みすぎない自然な雰囲気',
  image: '/images/styles/natural.svg',
  titleWord: '自然体な',            // プランタイトルに使う修飾語
  conceptPhrase: '作り込みすぎない自然な質感を大切にしながら',  // コンセプト文に差し込む言葉
},
```

**テイスト画像を自店の施工写真に差し替える手順**

1. 写真を `public/images/styles/` に置きます。例：`public/images/styles/natural.jpg`
2. `image: '/images/styles/natural.jpg',` に書き換えます。
3. 写真は **横長（4:3）・幅800px 程度**が最もきれいに表示されます。

> 画像が用意できていない場合や、パスを間違えた場合でも、自動でグラデーション背景が表示されるので**レイアウトは崩れません**。

### 6. 色の変更

`colors:` の中を編集します。

```ts
{ id: 'white', name: 'ホワイト', hex: '#FFFFFF', isLight: true },
{ id: 'pink',  name: 'ピンク',   hex: '#F0B4C2' },
```

- `hex` … 色見本に表示される色
- `isLight: true` … 白っぽい色に付けると、枠線が付いて見やすくなります
- 複数色をまとめて表したいとき（ニュアンスカラーなど）は `gradient` を使います。

```ts
{
  id: 'nuance',
  name: 'ニュアンスカラー',
  hex: '#C4B8AC',
  gradient: ['#DAD0C4', '#BFAFA4', '#A8A093'],
},
```

### 7. 季節の花データの変更

**2段階**になっています。

**① まず花を登録します（`flowers:`）**

```ts
{
  id: 'tulip',                            // 内部で使うID
  name: 'チューリップ',                     // 花名
  image: '/images/flowers/tulip.svg',      // 画像
  feature: '柔らかな曲線と豊富な品種。会場に軽やかな春の印象を添えます。',
  mainColors: '白／ピンク／赤／黄／紫',       // 主な色
  priceLevel: 'affordable',                // 価格帯の目安
  availability: 'stable',                  // 流通の安定性
},
```

`priceLevel` は次の3つから選びます。

| 書く値 | 画面の表示 |
| --- | --- |
| `'affordable'` | 比較的取り入れやすい |
| `'standard'` | 標準的 |
| `'premium'` | 高価になりやすい |

`availability` は次の3つから選びます。

| 書く値 | 画面の表示 |
| --- | --- |
| `'stable'` | 比較的安定 |
| `'varies'` | 時期により変動 |
| `'limited'` | 入荷が限られる場合がある |

**② 月ごとのおすすめ花を指定します（`monthlyFlowers:`）**

```ts
monthlyFlowers: {
  1: ['tulip', 'sweetpea', 'ranunculus', 'anemone', 'cymbidium'],
  2: ['tulip', 'sweetpea', 'ranunculus', 'mimosa', 'anemone'],
  // …12月まで
},
```

左の数字が月、`[ ]` の中が ① で登録した花の `id` です。
**地域や仕入れ先に合わせて、この並びを書き換えてください。**
花の数は5つでなくても構いません（3つでも8つでもOKです）。

### 8. 装花場所の変更

`decorationAreas:` の中を編集します。

```ts
{ id: 'entrance', name: 'エントランス', description: '会場の第一印象をつくる入口の装花', weight: 4 },
```

`weight`（重み）は予算配分に使われます。数字が大きいほど多く配分されます。

| 装花の規模 | weight の目安 |
| --- | --- |
| 大きな装花（メインステージ、吊り装花、高砂） | 4〜5 |
| 中くらいの装花（受付、床置き、カウンター） | 2〜3 |
| 小さな装花（サインボード、お手洗い、ケーキ装花） | 1 |

**すべてのシーンで表示する場所**は `commonDecorationAreaIds:` に id を並べます。
**特定のシーンだけで表示する場所**は、`scenes:` の `extraAreaIds` に id を書きます。

### 9. 予算配分ルールの変更

```ts
budgetRules: {
  priorityCoefficients: {
    high: 1.5,    // 優先したい
    medium: 1.0,  // できれば入れたい
    low: 0.5,     // 予算があれば
  },
  setupFeeRatio: 0.15,    // 搬入設営費として確保する割合（15%）目安 0.10〜0.20
  removalFeeRatio: 0.08,  // 撤去費として確保する割合（8%）目安 0.05〜0.10
  roundUnit: 1000,        // 金額の丸め単位（円）
},
```

**計算の流れ**

1. 予算総額を求めます（直接入力された金額、または予算帯の代表金額）
2. 「搬入設営費を含む」が選ばれていれば `setupFeeRatio` 分を先に確保します
3. 「撤去費を含む」が選ばれていれば `removalFeeRatio` 分を先に確保します
4. 残りを **装花場所の `weight` × 優先度の係数** の比率で配分します

**予算帯の金額**は `budgetRanges:` で変更できます。

```ts
{ id: '100kTo300k', label: '10万円〜30万円', representativeAmount: 200000 },
```

`representativeAmount` は、その予算帯を選んだときに配分計算で使う金額です。
「まだ決めていない」は `null` にしておくと、**金額を出さず割合だけ**表示します。

### 10. 問い合わせ先の設定

結果画面の「この内容で花屋に相談する」ボタンの動作を決めます。

```ts
contactChannel: {
  type: 'mailto',                  // ← ここを変えると遷移先が変わります
  mailTo: 'contact@example.com',   // type が 'mailto' のときの宛先
  url: '',                         // それ以外のときの遷移先URL
  buttonLabel: 'この内容で花屋に相談する',
  note: 'ボタンを押すと、入力内容の要約が入った状態でご相談いただけます。',
},
```

| `type` に書く値 | 動作 | 設定するもの |
| --- | --- | --- |
| `'mailto'` | メールソフトが開き、件名と本文が自動入力されます | `mailTo` |
| `'googleForm'` | Googleフォームを開きます | `url` |
| `'externalForm'` | 外部フォーム（formrun、Tally など）を開きます | `url` |
| `'line'` | LINE公式アカウントを開きます | `url` |

**mailto の場合の件名の例**

```
装花相談：2026年10月15日 ウェディング装花について
```

本文には、プランタイトル・開催情報・予算・テーマ・カラー・花材・装花場所・予算配分・連絡先の要約が自動で入ります。

> ℹ️ メールソフトの制限により、本文が長すぎると開けないことがあるため、
> 本文は約1800文字で自動的に区切られます。全文が必要な場合は
> 「相談内容をコピー」ボタンや「印刷・PDF保存」をご利用ください。

### 11. Googleフォームへの接続方法

1. Googleフォームを作成します（例：「お名前」「メールアドレス」「電話番号」「ご相談内容」）。
2. フォーム編集画面の右上［**⋮**］→［**事前入力したURLを取得**］をクリックします。
3. 各項目に適当な文字（例：`テスト`）を入れて［**リンクを取得**］→［**リンクをコピー**］します。
4. コピーしたURLは次のような形をしています。

   ```
   https://docs.google.com/forms/d/e/XXXXXXXX/viewform?usp=pp_url&entry.1234567890=テスト&entry.9876543210=テスト
   ```

5. `?` より前の部分（`https://docs.google.com/forms/d/e/XXXXXXXX/viewform`）を `url` に、
   `entry.1234567890` のような番号を `googleFormEntryIds` に貼り付けます。

```ts
contactChannel: {
  type: 'googleForm',
  url: 'https://docs.google.com/forms/d/e/XXXXXXXX/viewform',
  googleFormEntryIds: {
    name: 'entry.1234567890',     // お名前の項目
    email: 'entry.2345678901',    // メールアドレスの項目
    phone: 'entry.3456789012',    // 電話番号の項目
    summary: 'entry.4567890123',  // ご相談内容（プラン要約が自動で入ります）
  },
  buttonLabel: 'この内容で花屋に相談する',
  note: 'ボタンを押すとGoogleフォームが開きます。',
},
```

> 自動入力が不要な場合は `googleFormEntryIds` の中身をすべて `''` のままにしておいてください。
> `summary` に入るテキストは長いため、Googleフォーム側の項目は「**段落**」形式にしてください。

### 12. 注意事項・法的文書の変更

```ts
disclaimers: {
  top: [ /* トップページに表示 */ ],
  flower: [ /* 季節の花のステップに表示 */ ],
  result: [ /* 結果画面に表示 */ ],
},

```

`[ ]` の中に `'文章',` を追加すると、その分だけ行が増えます。

```ts
{
  heading: '1. 基本方針',
  paragraphs: [
    '1つ目の段落…',
    '2つ目の段落…',
  ],
},
```

## 画像ファイルの保存場所

すべての画像は `public/` フォルダに置きます。
`public/images/logo.png` に置いたファイルは、設定ファイルでは `'/images/logo.png'` と書きます。

```
public/
└─ images/
   ├─ logo.svg          ← ロゴ
   ├─ scenes/           ← シーンの画像（8枚）
   ├─ styles/           ← テイストの画像（12枚）
   └─ flowers/          ← 花の画像（28枚）
```

初期状態では、すべて仮画像（SVG）が入っています。
自店の写真に差し替える場合は、**同じファイル名の .jpg を置いて設定ファイルの拡張子を変える**か、
新しいファイル名で置いて設定ファイルのパスを書き換えてください。

推奨サイズの目安：

| 用途 | サイズ | 形式 |
| --- | --- | --- |
| シーン／テイスト | 横800 × 縦600 px 程度 | JPG |

## 買い切り販売時の複製方法

1. このフォルダ全体をコピーします（`node_modules` と `.next` フォルダは**含めない**でください。容量が大きく、`npm install` で再生成されます）。
2. コピー先で `package.json` の `"name"` を、そのお店用の名前に変更します（半角英数字とハイフンのみ）。
3. `src/config/shop.ts` を、そのお店の内容に書き換えます。
4. `public/images/` の画像を、そのお店の写真に差し替えます。
5. `npm install` → `npm run build` でエラーが出ないことを確認します。
6. [Vercel へのデプロイ方法](#vercel-へのデプロイ方法) の手順で公開します。

**1店舗＝1デプロイ**が基本の構成です。設定ファイルと画像を差し替えるだけで、何店舗分でも複製できます。

- 花材は自然物のため、色・形・大きさ・開花状態に個体差があります。
- 選択された花材の入荷や使用を保証するものではありません。

これらの文言は `src/config/shop.ts` の `disclaimers` で変更できます。
**お店の実情に合わせて、必ず内容をご確認ください。**

### データの取り扱いについて

- 入力内容はお客様のブラウザ（localStorage）にのみ保存されます。サーバーには送信されません。
- アップロードされた参考画像もブラウザ内で処理され、サーバーには保存されません。
- ブラウザの保存容量には上限があります。画像が多すぎて保存できない場合は、画像を除いて保存し、画面に案内を表示します。
- お客様がブラウザのデータを消去すると、入力内容も消えます。
